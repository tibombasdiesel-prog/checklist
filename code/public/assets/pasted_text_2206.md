Gostaríamos de criar um novo cargo no aplicativo, além do cargo já existente de Colaborador, que atualmente é responsável por realizar os checklists.

1. Novo cargo: Recepção / Veículo Novo

Esse cargo terá como principal função analisar os checklists realizados e realizar a abertura da Ordem de Serviço (O.S.).

2. Notificações

Sempre que um novo checklist for criado, o sistema deverá notificar automaticamente todos os usuários que possuam o cargo de Recepção / Veículo Novo.

A notificação servirá como alerta para que a recepção acesse o checklist e realize a abertura da O.S.

3. Visualização do checklist

O usuário com o cargo de Recepção deverá:

Ter acesso completo à visualização do checklist (informações, fotos, observações, odômetro etc.).

Não poderá editar nenhuma informação do checklist.

Ter acesso a todos os checklists já realizados, para consulta e controle.

4. Campo de Odômetro

Durante o preenchimento do checklist, deverá existir um campo obrigatório para inserção do odômetro do veículo.

Essa informação é essencial, pois a recepção necessita do odômetro para abrir a O.S..

5. Abertura da O.S. e status “Pronto”

O usuário da Recepção deverá ter uma opção “Pronto”, indicando que a Ordem de Serviço já foi aberta.

Após marcar como “Pronto”, o checklist deverá exibir um ícone em formato de “V”, sinalizando visualmente que a O.S. correspondente já foi criada.

Esse status serve apenas como controle interno, sem alterar os dados do checklist.

6. Chat interno

Implementar um chat interno no aplicativo.

A Recepção poderá:

Selecionar um ou mais colaboradores específicos para enviar mensagens.

Tirar dúvidas ou solicitar informações adicionais relacionadas ao checklist ou ao veículo.

7. Objetivo geral

O objetivo é garantir que a Recepção tenha total visibilidade dos checklists realizados, com todas as informações necessárias para a abertura da Ordem de Serviço, sem permissão de edição, apenas com controle de status e comunicação eficiente com os colaboradores.
